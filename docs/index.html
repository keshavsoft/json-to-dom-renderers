Design Patterns

Architectural Principles

Built upon clean software engineering disciplines: Screaming Architecture, Pure DOM builders, and explicit parameter pipelines.

Screaming Architecture Pipeline

Every component separates data modeling, specification generation, and DOM rendering:

  1. Store Layer (TableStore, FormStore, DataListStore): Ingests inputs, manages state, computes active columns, evaluations, and aggregations.
  2. Builder Layer (buildTable, buildForm, buildDataList): Transforms state into pure JSON element specifications conforming to json-to-dom schema.
  3. Engine Layer (json-to-dom): buildSpecElement({ inSpec }) produces high-speed native DOM nodes without virtual DOM diffing.
  4. Repaint Layer: Optimized repainters (repaintBody, repaintFoot) update specific DOM subtrees without rebuilding the entire container.
in & local Parameter Convention

Strict naming convention enforced across all constructors and functions to maximize clarity and avoid unintentional mutation: 

// Strict in / local convention
export function processRecords({ inData, inConfig }) {
    // 1. Assign to local variables
    const localData = inData || [];
    const localConfig = inConfig || {};

    // 2. Use local variables for all operations
    return localData.filter(item => localConfig.match(item));
}
API Reference

The Three Core Renderers

Each renderer is a standalone class that can be used independently or orchestrated together.

Table
Class

Renders a data table with dynamic serial numbers, striped/hover rows, sortable columns, and multi-tier summary footers.

Key Options:
  • data / inData: Array of row objects
  • columns / inColumns: Column definitions
  • config / inConfig: Active columns, row classes, footers
  • targetContainerId: DOM element ID
Public Methods:
  • .render(): Builds & mounts DOM
  • .filterStateData({ query }): Filters state
  • .repaintBody(): Re-renders tbody
  • .repaintFoot(): Re-evaluates tfoot
  • .refreshTable(): Full state refresh
Form
Class

Constructs filter/input forms matching active columns with inline action buttons and automatic list bindings for HTML5 datalists.

Key Options:
  • columns / inColumns: Master column list
  • config / inConfig: Active body columns & classes
  • targetContainerId: DOM element ID
Public Methods:
  • .render(): Returns { treeWithIds, spec, element }
  • .getControlsTree(): Returns pruned interactive elements tree
DataList
Class

Analyzes dataset values, computes value frequencies, and generates native HTML5 <datalist> elements with top-N limits.

Key Options:
  • data / inData: Active dataset
  • columns / inColumns: Column definitions
  • config / inConfig: Active datalist keys, topN
  • targetContainerId: Container ID
Public Methods:
  • .render(): Mounts datalist elements
  • .update({ data }): Reactively recalculates frequencies
Deployment

CDN & Quick Start

Integrate directly into any web application via jsDelivr CDN without bundlers or build steps.

1. Include Dependencies

Include Bootstrap 5 and the json-to-dom engine:

<!-- Bootstrap 5 CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- json-to-dom CDN engine -->
<script type="module" src="https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom/docs/dist/v3/min.js"></script>
2. Import Renderers via ESM 
// Import Table, Form, and DataList directly from jsDelivr CDN
import { Table, Form, DataList } from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v9/min.js";
Complete Minimal Example 
<div id="filter-box"></div>
<div id="table-box"></div>
<div id="datalist-box"></div>

<script type="module">
  import { Table, Form, DataList } from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v9/min.js";

  const columns = [{ key: "name", label: "Item" }, { key: "qty", label: "Quantity" }];
  const data = [{ name: "Apples", qty: 10 }, { name: "Oranges", qty: 25 }];

  // 1. Table
  const table = new Table({ data, columns, targetContainerId: "table-box" });
  table.render();

  // 2. Form Filter
  const form = new Form({ columns, targetContainerId: "filter-box" });
  form.render();

  // 3. Autocomplete DataList
  const dataList = new DataList({ data, columns, targetContainerId: "datalist-box" });
  dataList.render();
</script>
