Recipe 1

Building a Table with Serials & Multi-Tier Footers

Render a rich table with automated row numbering (#), aggregate sums, and evaluated formula rows (GST taxes & Grand Totals): 

import { Table } from "https://keshavsoft.github.io/json-to-dom-renderers/dist/v14/min.js";

const table = new Table({
    inData: [
        { id: 1, item: "Apples", qty: 10, rate: 50, amount: 500 },
        { id: 2, item: "Oranges", qty: 5, rate: 40, amount: 200 }
    ],
    inColumns: [
        { key: "item", label: "Item Name", type: "string" },
        { key: "qty", label: "Qty", type: "number", align: "right" },
        { key: "rate", label: "Rate", type: "number", align: "right" },
        { key: "amount", label: "Amount", type: "number", align: "right" }
    ],
    inConfig: {
        serial: true,
        head: { columns: ["item", "qty", "rate", "amount"] },
        foot: {
            rows: [
                {
                    cells: {
                        item: { text: "Sub Total", colspan: 3 },
                        amount: { aggregate: "sum", format: "currency" }
                    }
                },
                {
                    cells: {
                        item: { text: "GST (18%)", colspan: 3 },
                        amount: { eval: "amount * 0.18", format: "currency" }
                    }
                },
                {
                    cells: {
                        item: { text: "Grand Total", colspan: 3 },
                        amount: { eval: "amount + (amount * 0.18)", format: "currency" }
                    }
                }
            ]
        }
    },
    inTargetContainerId: "table-container"
});

table.render();
Recipe 2

Generating a Search & Filter Form

Generate declarative form controls with search buttons and automatic linkage to HTML5 <datalist> elements: 

import { Form } from "https://keshavsoft.github.io/json-to-dom-renderers/dist/v14/min.js";

const form = new Form({
    inColumns: [
        { key: "item", label: "Item Name", type: "string" },
        { key: "category", label: "Category", type: "string" }
    ],
    inConfig: {
        fields: [
            {
                name: "item",
                type: "text",
                placeholder: "Search item name...",
                datalist: true,
                button: { text: "Search", class: "btn-outline-primary" }
            }
        ]
    },
    inTargetContainerId: "form-container"
});

form.render();
Recipe 3

Decoupled REST CRUD with createDataProvider

Decouple your networking logic from UI components with a uniform read/create provider: 

import { Table, createDataProvider } 
    from "https://keshavsoft.github.io/json-to-dom-renderers/dist/v14/min.js";

// Initialize uniform REST provider
const dataProvider = createDataProvider({
    inReadUrl: "/api/orders/list",
    inCreateUrl: "/api/orders/new"
});

// Pass to Table instance
const table = new Table({
    columns,
    config: tableConfig,
    dataProvider
});

// Asynchronously load and render
await table.render({ inContainerId: "table-container" });
Recipe 4

Dynamic Theme Switching

Switch visual appearances instantaneously across Table, Form, and DataList without re-querying or rebuilding data: 

// Instantaneously switch themes across components:
table.setTheme({ inTheme: "dark" });
form.setTheme({ inTheme: "dark" });
dataList.setTheme({ inTheme: "dark" });

// Supported out-of-the-box:
// "default" | "light" | "extraLight" | "dark" | "extraDark"
